One question, taken all the way.

Each of these starts with a case simple enough to do on paper, then changes one thing so that the paper method stops working. The formula is derived, the keystrokes are given in full, and the same answer is then found a second way on a graph — because an answer you have only seen once is a number you are trusting, not a number you know.

How these are written

Every figure here has been checked twice.

Nothing is quoted from memory. Each number on these pages is produced by the formula shown beside it and verified independently before publishing, and where a result is approximate the page says so rather than rounding the doubt away. The models are ordinary textbook ones — they are stated, along with what they ignore, so you can see exactly where each stops describing the real world.

There is one rule underneath all of it: a number is only printed to the precision it has earned. Arithmetic is exact and quoted in full; a measurement is quoted to the figures the measurement supports; and a numerical result from the graph carries the uncertainty the app states for it. Where those three disagree about the same quantity — and they do, on several of these pages — the disagreement is explained rather than rounded away.
