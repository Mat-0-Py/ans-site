Definitions

  • The centistokes is 10⁻⁶ m²/s. Lubricating oil grades are specified in cSt at 40 °C and 100 °C.
  • The square metre per second is the SI unit of kinematic viscosity: dynamic viscosity divided by density.
  • Kinematic viscosity is dynamic viscosity divided by density. Without a density, Pa·s cannot be converted to m²/s.
  • Every unit in the menus is exact by definition, so the only rounding on this page is the one you choose for the display.

How it works

Every value is converted into square metres per second and then back out into the unit you asked for. One route covers every pairing in the menus, so an unusual combination is no less accurate than a common one, and adding a unit affects only that unit.

Both boxes are live. Whichever one you last typed in is the source, changing either menu recalculates straight away, and Swap exchanges the units and the values so the number you are reading stays where you are looking.

Display precision sets a maximum number of significant figures and trims trailing zeroes, so it changes what you see and never what was calculated. The editable box always holds a plain number at full working precision, so you can carry on from either side.

Common questions this answers: how many square metres per second in a centistokes (1×10⁻⁶), how many centistokeses in a square metre per second (1000000), and what 100 cSt is in square metres per second (1×10⁻⁴ m²/s).
