Definitions

  • The centipoise is exactly one millipascal second, chosen so that water at 20 °C is almost exactly 1 cP.
  • The pascal second is the SI unit of dynamic viscosity — resistance to shear.
  • Dynamic viscosity and kinematic viscosity are different quantities. Converting between them requires density, so they have separate pages.
  • Every unit in the menus is exact by definition, so the only rounding on this page is the one you choose for the display.

How it works

Every value is converted into pascal seconds and then back out into the unit you asked for. One route covers every pairing in the menus, so an unusual combination is no less accurate than a common one, and adding a unit affects only that unit.

Both boxes are live. Whichever one you last typed in is the source, changing either menu recalculates straight away, and Swap exchanges the units and the values so the number you are reading stays where you are looking.

Display precision sets a maximum number of significant figures and trims trailing zeroes, so it changes what you see and never what was calculated. The editable box always holds a plain number at full working precision, so you can carry on from either side.

Common questions this answers: how many pascal seconds in a centipoise (0.001), how many centipoises in a pascal second (1000), and what 1000 cP is in pascal seconds (1 Pa·s).
