Definitions

  • Revolutions per minute counts whole turns. One rpm is 2π/60 rad/s, so 1000 rpm is about 104.7 rad/s.
  • Radians per second is the SI measure of rotation rate, and the ω that appears in physics equations.
  • Angular velocity measures angle swept per second. Revolutions per minute become rad/s using 2π radians per revolution; ordinary frequency in hertz is kept separate.
  • Every unit in the menus is exact by definition, so the only rounding on this page is the one you choose for the display.

How it works

Every value is converted into radians per second and then back out into the unit you asked for. One route covers every pairing in the menus, so an unusual combination is no less accurate than a common one, and adding a unit affects only that unit.

Both boxes are live. Whichever one you last typed in is the source, changing either menu recalculates straight away, and Swap exchanges the units and the values so the number you are reading stays where you are looking.

Display precision sets a maximum number of significant figures and trims trailing zeroes, so it changes what you see and never what was calculated. The editable box always holds a plain number at full working precision, so you can carry on from either side.
