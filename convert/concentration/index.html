Definitions

  • Moles per litre — molar concentration — is the standard bench chemistry unit. It equals 1000 mol/m³.
  • Millimoles per litre is the unit clinical results are reported in. Converting to mg/dL needs the substance's molar mass, so it is not a unit conversion.
  • Mass concentration and amount concentration are not interchangeable without the substance's molar mass. This page therefore does not fake mg/dL to mmol/L.
  • Every unit in the menus is exact by definition, so the only rounding on this page is the one you choose for the display.

How it works

Every value is converted into moles per cubic metre and then back out into the unit you asked for. One route covers every pairing in the menus, so an unusual combination is no less accurate than a common one, and adding a unit affects only that unit.

Both boxes are live. Whichever one you last typed in is the source, changing either menu recalculates straight away, and Swap exchanges the units and the values so the number you are reading stays where you are looking.

Display precision sets a maximum number of significant figures and trims trailing zeroes, so it changes what you see and never what was calculated. The editable box always holds a plain number at full working precision, so you can carry on from either side.

Common questions this answers: how many millimoles per litre in a mole per litre (1000), how many moles per litre in a millimole per litre (0.001), and what 1 mol/L is in millimoles per litre (1000 mmol/L).
